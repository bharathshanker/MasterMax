# Pitch Expert

Pitch Expert is a web application for sales teams to record their sales pitches and receive actionable feedback.

## Features
- Record and upload sales pitch audio
- View and playback previous recordings
- (Coming soon) Automated feedback on improvement areas

## Tech Stack
- Frontend: React
- Backend: Node.js (Express)
- Database: MongoDB (can be swapped for PostgreSQL)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Setup

#### 1. Backend
```
cd backend
npm install
npm run dev
```

#### 2. Frontend
```
cd frontend
npm install
npm start
```

### Project Structure
- `/frontend` — React app
- `/backend` — Express API
